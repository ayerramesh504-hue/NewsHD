# NewsHD

NewsHD is a news portal web application built using PHP, CodeIgniter 4, and MySQL.

## Features
- News and article management
- Category management
- User management
- Search functionality
- Responsive user interface
- Admin dashboard

## Requirements
- PHP
- Composer
- MySQL or MariaDB
- Apache server (XAMPP recommended)

## Local Setup
1. Clone or download the project.
2. Install dependencies using `composer install`.
3. Configure your database settings in the `.env` file.
4. Create the required database and import your database schema or backup.
5. Configure the application and run it locally.
